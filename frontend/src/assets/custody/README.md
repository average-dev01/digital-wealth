# Custody connector logos

Bundled assets for the connector grid on `/dashboard/account-keyword`
(see `CUSTODY` in that page). Each entry is `import`ed by exact filename, so
renaming a file means updating its `import` line too.

Current files:

- `binance.png` &rarr; Binance
- `trust.png` &rarr; Trust
- `Bitget.png` &rarr; Bitget (capital B  the import string must match)
- `coinbase.png` &rarr; Coinbase
- `metamask.png` &rarr; Metamask
- `iogo.png` &rarr; "Other" (WalletConnect mark)

Shown at a 4:3 aspect ratio, max ~180px wide on screen.
